# b18 Synopsys example

This example synthesizes the ITC'99 b18 VHDL design and inserts scan and logic BIST with Design Compiler, then runs scan and LBIST ATPG and simulation with TetraMAX. The design and technology files are supplied by the user; they are not stored here.

## Configure

Copy `setup.local.sh.example` to `setup.local.sh` and replace the placeholder paths with absolute paths to your b18 VHDL file, Design Compiler `.db` library, DesignWare `dw_foundation.sldb`, and TetraMAX technology Verilog library. The local file is ignored by Git. You can also export the four `B18_*` input variables in your shell instead of creating it.

## Run

From a Bash shell, in any directory:

```bash
source /path/to/dft_examples/synopsys_flow/b18/setup.sh
cd "$B18_WORK_DIR"
dc_shell -f "$B18_EXAMPLE_DIR/bist_insertion.tcl"
tmax -shell -file "$B18_EXAMPLE_DIR/atpg_bist_simulation.tcl"
tmax -shell -file "$B18_EXAMPLE_DIR/atpg_simulation_scan.tcl"
```

The two ATPG scripts read the netlist and their respective LBIST or SCAN protocol generated by the first script from the current directory. Run the Design Compiler command first, then either or both TetraMAX commands in the same work directory. The default work directory is `b18/work/`, which is ignored by Git. Override `B18_WORK_DIR` with an absolute path before sourcing `setup.sh` if needed. Both Synopsys executables must be available in `PATH` and licensed on your machine.
